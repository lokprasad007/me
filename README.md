# NEXUS 3.0 &bull; VTU 3rd Semester Academic Portal & Knowledge Vault

An immersive, high-performance web dashboard designed to explore, read, and master all 3rd Semester academic study materials, lecture slides, textbooks, question banks, and career roadmaps.

---

## 🚀 Quick Start (How to Launch)

You can launch the portal in two easy ways:

### Method 1: One-Click Launcher (Recommended)
Double-click **`Launch-StudyHub.bat`**.
> This starts a lightweight background local HTTP server and automatically opens the portal in your default web browser at `http://localhost:8080`.

### Method 2: Direct Offline Launch
Double-click **`index.html`** to open it directly in Google Chrome, Microsoft Edge, Brave, or Firefox.
> Fully functional 100% offline without needing an active internet connection.

---

## 🌟 Key Features

1. **In-Browser Document Reader (Focus Mode)**:
   - Fullscreen reading modal with built-in PDF viewer.
   - Quick navigation between documents using `←` and `→` keyboard arrows.
   - One-click buttons to open in a full browser tab or download locally.
   - Slide breakdown viewer for `.ppt` presentations.

2. **VTU 3rd Sem Interactive Syllabus & Exam Checklist**:
   - Module-by-module breakdown (Modules 1 to 5) for both **Operating Systems (BCSOS303)** and **Data Structures (BCIDS302)**.
   - Interactive topic checkboxes with auto-saving to browser storage.
   - Live readiness percentage bar.
   - **"Study Module Notes"** button to filter documents directly to that module.

3. **Smart Live Search & Filtering**:
   - Instant search across file titles, authors, course codes, and syllabus topics.
   - Category filter pills: *Operating Systems*, *Data Structures*, *Architecture*, *Question Banks*, *Roadmaps*.
   - Star/Bookmark favorite documents (saved in `localStorage`).

4. **Productivity & Study Tools**:
   - **Integrated Pomodoro Focus Timer** (25 min focus / 5 min break) with procedural audio bell chimes.
   - **Document Scratchpad**: Take notes while reading any file; auto-saved per document.
   - **Central Revision Notepad**: Comprehensive markdown notepad with instant `.md` file export.
   - **Procedural Audio FX**: Tactile UI sound effects synthesized using the Web Audio API.

5. **Aesthetic Cyber-Glassmorphic Themes**:
   - 🌌 **Cyberpunk Obsidian** (Default neon cyan/purple)
   - 🌿 **Emerald Matrix** (Terminal hacker green)
   - ☀️ **Solar Amber** (Warm amber gold)
   - 📖 **Daylight Academic** (Clean light mode)

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `/` | Focus search bar |
| `Esc` | Close reader / modals |
| `←` / `→` | Previous / Next document in reader mode |
| `★` | Bookmark / Favorite document |
